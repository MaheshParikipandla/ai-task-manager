# AI Task Manager Frontend

This is the React frontend for the AI Task Manager project.

## Requirements

- Node.js
- npm

## Setup

1. Copy `.env.example` to `.env` and adjust the API base URL if needed.
2. Install dependencies:

```bash
npm install
```

3. Start the app:

```bash
npm run dev
```

The development server will usually run at `http://localhost:5173`.

## Available scripts

- `npm run dev` - start the Vite development server
- `npm run build` - build the production bundle
- `npm run preview` - preview the production build
